Function	Definition
arr.length	Returns the size (number of elements) of the array.
Arrays.sort(arr)	Sorts the array in ascending order.
Arrays.toString(arr)	Converts array into a readable string format.
Arrays.binarySearch(arr, key)	Searches an element in a sorted array and returns its index.
Arrays.fill(arr, value)	Fills all array elements with the given value.
Arrays.copyOf(arr, newSize)	Creates a new array by copying elements from the original array.
Arrays.copyOfRange(arr, from, to)	Copies a specific range of elements into a new array.
Arrays.equals(arr1, arr2)	Compares two arrays and returns true if they are equal.
Arrays.deepEquals(arr1, arr2)	Compares multidimensional arrays deeply.
Arrays.compare(arr1, arr2)	Compares two arrays lexicographically.
Arrays.mismatch(arr1, arr2)	Returns the first index where two arrays differ.
Arrays.parallelSort(arr)	Sorts large arrays using multiple threads.
Arrays.stream(arr)	Converts array into a Stream for processing.
Arrays.asList(arr)	Converts an array into a List (mostly used with objects).


## Array Operations

1. Access
Definition: Retrieve an element using its index.
Code:
int value = arr[2];
Time Complexity: O(1)

--------------------------------------------------

2. Insert
Definition: Add a new element at a specific position.
Code:
arr[index] = value;
Time Complexity: O(n)

--------------------------------------------------

3. Delete
Definition: Remove an element and shift remaining elements.
Code:
for(int i=index; i<size-1; i++)
{
    arr[i] = arr[i+1];
}
size--;
Time Complexity: O(n)

--------------------------------------------------

4. Search
Definition: Find an element in the array.
Code:
for(int i=0; i<arr.length; i++)
{
    if(arr[i] == target)
        return i;
}
Time Complexity: O(n)

--------------------------------------------------

5. Traverse
Definition: Visit every element one by one.
Code:
for(int i=0; i<arr.length; i++)
{
    System.out.println(arr[i]);
}
Time Complexity: O(n)

--------------------------------------------------

6. Update
Definition: Change the value of an existing element.
Code:
arr[2] = 100;
Time Complexity: O(1)
